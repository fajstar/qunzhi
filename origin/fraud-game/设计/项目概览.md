# 欺诈游戏 · AI竞技场 — 项目概览

## 项目定位
一个基于 LLM 驱动的多智能体博弈系统，6 名 AI 玩家在信息不完备的环境中通过交换线索、验证信息、战略投票来拼凑真相，最终猜出自己的颜色并存活。

## 核心理念
- **信息是货币**：游戏的核心资产是"线索"，所有互动围绕线索展开
- **合作与竞争并存**：玩家需要合作交换信息，但也要竞争获取更可靠的信息
- **没有预设敌人**：不确定性来自信息本身的质量，而不是某个特定角色
- **决策驱动演化**：每个玩家的认知框架和情感状态会随着决策结果而演化

## 核心机制
| 机制 | 说明 |
| :--- | :--- |
| 信息银行 | 线索的存储、交换、验证、声称系统 |
| 少数决 | 每日投票，少数派获得额外线索 |
| 公投 | 投票决定"哪条线索更可靠" |
| 验证权 | 唯一能确认线索真实性的工具 |
| 调查 | 获取线索的来源背景信息 |
| 认知框架 | 5维度长期人格底色 |
| 情感系统 | 4维度短期情绪波动 |
| 记忆系统 | L1/L2/L3 分层记忆，含遗忘和自动提炼 |
| 基因池 | 成功认知框架的跨局继承与变异 |

## 技术栈
- **后端**：Flask + OpenAI SDK（DeepSeek V4-Flash）
- **前端**：原生 HTML/CSS/JavaScript（SSE 实时推送）
- **存储**：JSON 文件（记忆、基因池、历史）
