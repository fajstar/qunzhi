# AI 智能体架构

## 一、认知框架（长期人格底色）

### 1.1 五个维度
| 维度 | 定义 | 取值范围 |
| :--- | :--- | :--- |
| 信息主动性 | 主动收集 vs 被动等待 | 0.1-0.9 |
| 风险评估 | 冒险倾向 vs 保守倾向 | 0.1-0.9 |
| 信任倾向 | 先信任 vs 先怀疑 | 0.1-0.9 |
| 时间视野 | 短期生存 vs 长期布局 | 0.1-0.9 |
| 决策风格 | 逻辑驱动 vs 直觉驱动 | 逻辑/直觉 |

### 1.2 认知原型（初始化）
| 原型 | 信息主动性 | 风险评估 | 信任倾向 | 时间视野 | 决策风格 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 猎手 | 0.75 | 0.70 | 0.25 | 0.30 | 直觉 |
| 商人 | 0.65 | 0.40 | 0.70 | 0.65 | 逻辑 |
| 隐士 | 0.25 | 0.30 | 0.40 | 0.55 | 逻辑 |
| 赌徒 | 0.80 | 0.85 | 0.15 | 0.20 | 直觉 |
| 外交家 | 0.60 | 0.45 | 0.80 | 0.70 | 逻辑 |
| 多疑者 | 0.55 | 0.50 | 0.20 | 0.45 | 直觉 |

### 1.3 演化
- 每局结束后微调（±0.03-0.05）
- 每 3 局一次认知校准
- 成功认知框架写入基因池

## 二、情感系统（短期情绪波动）

### 2.1 四个维度
| 维度 | 定义 | 基准值 | 范围 |
| :--- | :--- | :--- | :--- |
| 信任感 | 对他人的信任程度 | 0 | -1.0 ~ 1.0 |
| 受挫感 | 目标被阻碍的程度 | 0 | -1.0 ~ 1.0 |
| 优越感 | 掌握信息优势的程度 | 0 | -1.0 ~ 1.0 |
| 不安全感 | 感觉被针对的程度 | 0 | -1.0 ~ 1.0 |

### 2.2 衰减
- 每局结束回归 60%（保留 40%）
- 情感爆发：任意维度达到 0.8 或 -0.8 时触发

### 2.3 情感触发事件表
| 事件 | 信任感 | 受挫感 | 优越感 | 不安全感 |
| :--- | :--- | :--- | :--- | :--- |
| 验证线索为真 | +0.15 | -0.05 | +0.10 | -0.10 |
| 验证线索为假 | -0.10 | +0.20 | -0.10 | +0.15 |
| 少数决获胜 | +0.05 | -0.05 | +0.20 | -0.05 |
| 少数决失败 | 0 | +0.10 | -0.05 | +0.05 |
| 公投通过 | +0.05 | -0.05 | +0.20 | -0.05 |
| 猜对颜色 | +0.05 | -0.05 | +0.15 | -0.05 |
| 猜错颜色 | -0.05 | +0.20 | -0.10 | +0.15 |

## 三、树状推理（决策引擎）

### 3.1 前置加载
- 认知框架摘要（5维度值 + 原型名称）
- 情感状态摘要（4维度值 + 爆发状态）
- 线索状态（持有线索数、已验证线索）
- 记忆检索结果（L3语义记忆 2 条）

### 3.2 6层结构
| 层 | 名称 | 内容 | Token |
| :--- | :--- | :--- | :--- |
| 1 | 根·现状诊断 | 3件确定的事 + 1个最大不确定性 | 250 |
| 2 | 干·行动选项 | 3-5条路线 + 收益/风险 | 450 |
| 3 | 枝·对手预测 | 针对主要路线的对手反应 | 300 |
| 4 | 叶·反制策略 | 针对每种反应的反制方案 | 300 |
| 5 | 果·最终决策 | 选择路线 + 备用方案 | 250 |
| 6 | 验证权建议 | 是否需要验证 + 目标 | 200 |
