# 术语表

| :--- | :--- |
| 信息银行 | 线索的存储、交换、验证、声称系统 |

| 少数决 | 每日投票，少数派获胜获得额外线索 |
| 公投 | 玩家主动发起的高风险投票，验证线索可靠性 |
| 认知框架 | 5维长期人格底色 |
| 认知原型 | 6种预设认知框架（猎手/商人/隐士/赌徒/外交家/多疑者） |
| 情感系统 | 4维短期情绪波动 |
| 基因池 | 存储成功认知框架，供跨局继承 |

| L2情景记忆 | 跨局关键事件记忆 |
