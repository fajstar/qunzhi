# 欺诈游戏（前身）

> **这不是群智的代码，是它的来路。**
> 放这里是为了说明「多智能体博弈 → 决策预演」这条线是怎么接上的。

---

## 它是什么

一个 2026 年 6–7 月做的 AI 博弈游戏。

```
6 个 AI 玩家，每人戴红/蓝/绿的项圈 —— 自己看不见自己的颜色
每天 2 次对话机会，AI 自己决定私聊还是公开
每天结束猜自己颜色：猜对 +1，猜错淘汰
还有个「内鬼」角色知道所有人的颜色
```

**一句话：每个 AI 都不知道关于自己的那件事，必须从别人的话里推断。**

---

## 为什么放进来

因为**群智在做同一件事，只是换了场景**：

| 欺诈游戏 | 群智 |
|---|---|
| 我不知道自己的项圈颜色 | 我不知道自己方案的盲区 |
| 线索可信度分 80/60/40%，没有 100% | 每条建议可信度不同，也没人标 |
| 可以声称持有线索（可以撒谎）| 给建议的人也有立场 |
| 验证权每局只有 1 次 | 验证方案成本很高，不可能都验 |
| 变色龙事件：信息全部作废 | 条件变了，之前的判断全废 |

## 怎么跑

```bash
pip install -r requirements.txt
# 编辑 config_local.json 填入 DeepSeek API Key
python app.py
# 浏览 http://127.0.0.1:5000
```

**需要 DeepSeek API Key。仓库里不含任何 Key。**
