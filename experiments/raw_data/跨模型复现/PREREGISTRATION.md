# 跨模型复现性实验 · 预注册

> **本文档在跑实验之前写定。判定规则跑后不改。**
> 日期：2026-09-17

---

## 一、要回答的问题

我们最硬的一条结论是：**「6 个成员异构」明显优于「6 个成员完全同质」**
（p=0.0012，dz=−0.99；另一独立实验 p=0.015，d=1.38）。

**但那两个实验都在 DeepSeek 上跑的。**

评委一定会问：**「换个模型还成立吗？」**
如果换模型就不成立，那这条结论就不是"关于多智能体的规律"，而是"关于 DeepSeek 的特性"。
本次实验就是回答这一条。

---

## 二、设计（跑前固定）

### 2.1 条件（只比最关键的两个）

| 条件 | 配置 |
|---|---|
| **E1 异构** | 6 人，认知原型 / 专业 / 价值观**各不相同**（= 产品默认） |
| **E0 零异构** | 6 人**配置完全相同** |

### 2.2 模型（自变量）

| 模型 | 型号 | 说明 |
|---|---|---|
| GLM | `glm-4-flash` | 智谱 |
| Qwen | `qwen3.8-flash` | 阿里云百炼 |

**DeepSeek 的结果直接用历史实验**（`2026-09-16_人格消融_n20`，n=20），不重跑。

### 2.3 规模

- 题目：T1–T4（与历史实验**同一套题**，保证可比）
- 种子：1, 2
- 每个模型 **2 条件 × 4 题 × 2 种子 = 16 次**
- **两个模型共 32 次**

### 2.4 关键控制（防污染）

| 控制 | 做法 | 为什么 |
|---|---|---|
| **禁止模型回落** | 把引擎的 `call_with_retry` 整个替换成目标模型的直连实现，**失败即记失败，绝不回落到 DeepSeek** | 引擎自带"失败回落 DeepSeek"，如果不管，跑出来的可能是 DeepSeek 的结果 —— **实验会静默失效** |
| **记录实际模型** | 每次调用记下 API 返回的 `model` 字段 | 验证真实服务的模型，而不是我们以为的模型 |
| **引擎一致性** | 记录引擎 md5 | 保证与历史实验同一份代码 |
| **逐条记录 token** | 每次运行记 prompt/completion tokens | 便于算成本、也便于发现异常 |

---

## 三、指标

主指标与历史实验完全一致：**视角覆盖数（0–6）** —— 输出命中的专业维度数（关键词表不变）。
副指标：输出字数、均衡度、决策要素完备度、token、耗时。

**注意**：本实验 **n 较小（每条件每模型 8 次）**，因此：
- 只做**方向性判断**（E1 是否高于 E0），不宣称统计显著；
- 同时报告效应量与置信区间供参考。

---

## 四、判定规则（跑前定死，跑后不改）

对每个模型，比较 E1 与 E0 的视角覆盖数均值：

| 结果 | 结论 | 对应行动 |
|---|---|---|
| **两个模型都出现 E1 > E0** | 核心结论**跨模型稳健** | 材料里可以写"该结论不依赖特定模型" |
| **只有一个模型出现 E1 > E0** | 结论**部分依赖模型** | 材料里必须写明"在 X 模型上成立，Y 模型上未复现" |
| **两个模型都不出现或反向** | 核心结论**不稳健** | **材料里不得再把它当核心证据**，需重新审视 |

> **承诺**：无论结果如何如实写。若结论被证不稳健，我们按上表行动。

累计 token 超过 **5,000,000** 即停止（预估 32 次 × 约 45k ≈ 1.44M，留足余量）。

## 七、v2 修订（2026-09-18，**在跑任何正式运行之前**）

**触发原因**：v1 试跑发现两个问题 ——

1. **GLM 官方 API 拒绝「只有 system 一条消息」的请求**（实测 HTTP 400，code 1214），
   导致 GLM 侧 38% 的调用失败、报告退化成 800 字占位内容；
2. 三个模型各走各的平台（DeepSeek 官方 / 智谱 / 阿里），**协议不一致、key 三套**。

**同时，团队已统一走阿里云路线并取得 300 元算力支持。**

**v2 改了什么**：

| 项 | v1 | v2 |
|---|---|---|
| 调用渠道 | 三平台各自调用 | **全部经阿里云百炼（DashScope，OpenAI 兼容模式）** |
| 模型 | glm-4-flash / qwen3.8-flash | **qwen-flash / deepseek-v3.1 / glm-5**（均已实测可调） |
| 消息格式 | 只发 system | **统一发 system + user**（对三家都安全） |
| 校准作用 | —— | `deepseek-v3.1` 同时充当"换渠道后同族模型是否仍旧成立"的校准 |

**没有改的**：条件（E1/E0）、题目（T1–T4）、种子（1,2）、指标、判定规则、禁止回落的控制。

> **实测依据**（百炼可用模型探测，2026-09-17）：
> Qwen 全系可用；`deepseek-v3` / `deepseek-v3.1` / `deepseek-r1` 可用；
> `glm-5` 可用（`glm-4.5` 仅支持流式，故不用）。

**v2 规模**：3 模型 × 2 条件 × 4 题 × 2 种子 = **48 次**

**为什么这个实验现在更重要**：如果产品线整体转向百炼/Qwen，
那么**历史上所有实验（都在 DeepSeek 官方 API 上跑的）都面临"换平台后还成立吗"的问题**。
本实验直接回答它。

## 七、v4 修订：双端点 + 「思考开关」升级为受控因子

### 7.1 为什么必须加「思考」这一维（**回答：以前的实验没考虑过**）

**查证结果（2026-09-18 实测）**：

| 项 | 实测 |
|---|---|
| 历史实验用 `deepseek-chat` | 服务模型实际是 **`deepseek-flash`** |
| 它的思维链长度 | **0 字 → 非推理模型** |
| 结论 | **历史 172 次实验事实上全部在「无思考」档跑的** |

**但当时我们并没有把"思考"当作受控因子** —— 只是恰好用了非推理模型。

**而新版模型（qwen3.8-flash / deepseek-v4.1-flash / glm-5.3-flash）默认开启思考。**
如果不控制这一维就换模型，**无法区分差异来自"模型"还是来自"思考开关"** ——
这是一个此前未被识别的混淆因子。

**所以本次把它显式升级为实验因子。**

### 7.2 双端点设计

| 模型 | 渠道 | 型号 | 关思考写法（实测） |
|---|---|---|---|
| qwen | 阿里云百炼 | `qwen3.8-flash` | `enable_thinking: false` |
| deepseek | 阿里云百炼 | `deepseek-v4.1-flash` | `enable_thinking: false` |
| glm | **智谱官方（自有 key）** | **`glm-5.3-flash`** | `reasoning_effort: "low"` |

> 百炼上的 `ZHIPU/GLM-5.3-Flash` **未开通**（返回 "The product is not activated"），
> 而智谱官方有 `glm-5.3-flash` 可用，故 GLM 走智谱官方。
>
> 智谱官方明确回复：**「该模型始终思考，不支持关闭思考；请使用 low、high 或 max」** ——
> 故 GLM 侧用 `low`（实测思维链降到 0 字）。

### 7.3 因子与规模

| 因子 | 水平 |
|---|---|
| 模型 | qwen3.8-flash / deepseek-v4.1-flash / glm-5.3-flash |
| **思考** | **开（默认）/ 关（抑制参数）** |
| 条件 | E1 异构 / E0 零异构 |
| 题目 | T1–T4 |
| 种子 | 1, 2 |

**3 模型 × 2 思考档 × 2 条件 × 4 题 × 2 种子 = 96 次**

### 7.4 判定规则（跑前定死）

**主判定：核心结论「成员异构 > 完全同质」在 6 个组合（3 模型 × 2 档）里成立几个？**

| 成立组合数 | 结论 | 行动 |
|---|---|---|
| **6/6** | 极稳健 | 可写"不依赖模型、也不依赖思考开关" |
| 4–5/6 | 基本稳健 | 列出成立的组合，不成立的如实标注 |
| ≤3/6 | **不稳健** | **不得再作为核心证据** |

**思考档附加判定**：

| 观察 | 结论 |
|---|---|
| 「关思考」覆盖数不明显低于「开思考」（差 < 0.5 维） | **生产默认关思考**（更便宜更快），并公布节省幅度 |
| 「关思考」明显更低 | 生产必须保留思考，如实写明成本代价 |

**额外分析（探索性）**：思考档对**成本与耗时**的影响幅度（token / 秒）。

### 7.5 成本控制

上限 **8,000,000 token**。若触顶，**优先砍掉「思考开」组** ——
因为「关思考」才是生产要用的形态，优先级更高。
