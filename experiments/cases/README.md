## 案例一：电气工程综合设计（Buck 变换器）

**题目来源**：24 级电气工程综合设计课程（100W Buck，PMOSFET + TMS320F28335 DSP）
**群智发现的关键盲区（单一 AI 未给出）**：
1. 🚨 提出**三电平 Buck** 备选拓扑——占空比 0.625-0.75 恰为其理想区间，PMOS 耐压减半
2. 🚨 **硬件比较器直封 PWM（<1μs）> DSP 软件保护（>10μs）**——100kHz 下软件逐周期限流来不及
3. 🚨 **F28335 PWM 硬件同步触发 ADC** 是架构事实，别用软件补偿
4. 🚨 保护静默关断会让用户反复上电 → 需分级告警

📂 `01_电气工程_Buck/`：单一AI直答 + 群智6人团队报告 + 讨论日志 + 案例说明

## 案例二：师范教研（课堂参与度）

**场景**：师范生课堂参与度提升（师范院校典型教研问题）
**群智发现的关键盲区（单一 AI 未给出）**：
1. 🚨 **"沉默可能是对低质量教学的消极抵抗"**——提升参与度不能替代提升内容质量
2. 🚨 **师范生不是同质群体**——方案不能以"平均学生"为原型
3. 🚨 **表演性参与风险**——只奖励发言会逼出"看着热闹、脑子没动"的表演
4. 🚨 机制必须内生课堂时间结构，否则教师负荷过载而缩水
