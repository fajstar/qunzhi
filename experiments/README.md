## 批次二：三臂对照（32 次）

| 项 | 值 |
|---|---|
| **时间** | 2026-09-15 |
| **规模** | 4 课题 × 2 种子 × 4 臂 = 32 次 |
| **数据位置** | `2026-09-15_三臂对照/runs/`（32 个 JSON）、`PREREGISTRATION.md`（预注册）、`analysis/` |
| **性质** | **结论依据** |
| **测什么** | 多智能体团队 vs 同质团队 vs 单模型多视角 |

### 结果

| 臂 | 配置 | 视角覆盖 | n |
|---|---|---|---|
| **A** | 6 人格异构团队 | **5.50** | 8 |
| **B** | 6 人同质副本 | **4.25** | 8 |
| **C** | 单模型多视角（1 次调用）| **5.88** | 8 |

- A − B = **+1.25** → 异构显著优于同质
- A − C = **−0.38** → 与单模型判不出差别（TOST p=0.026）
- **B − C = −1.62** → **同质团队还不如单模型**

**最后一行是这组实验最重要的发现**：把 6 个 AI 设成一样，覆盖度比一个模型给个多视角提示词还低。

**所以：异构不是加分项，是及格线。**

## 批次三：人格消融（140 次）

| 项 | 值 |
|---|---|
| **时间** | 2026-09-16 |
| **规模** | 7 配置 × 4 课题 × 5 种子 = 140 次，每臂 n=20 |
| **数据位置** | `2026-09-16_人格消融_n20/runs/`（140 个 JSON）、`analysis/ablation_n20.json` |
| **性质** | **结论依据** |
| **测什么** | 三个人格维度里，哪个真的有用 |

### 7 个配置

| 配置 | 只改什么 | 覆盖 | 与全同质之差 |
|---|---|---|---|
| E0 | （基线）6 人完全相同 | 4.60 | — |
| E1 | 三维全异构 | 5.65 | **+1.05** |
| E2 | 仅认知原型 | 4.50 | −0.10 |
| E3 | 仅专业背景 | 5.45 | +0.85 |
| E4 | 仅价值取向 | 5.30 | +0.70 |
| E5 | 3 人团队 | 5.00 | +0.40 |
| E5b | 6 人团队 | 5.65 | +1.05 |

### 结论

| 维度 | 覆盖增量 | p | 决策要素增量 | p | 判定 |
|---|---|---|---|---|---|
| 认知原型 | −0.10 | 0.6493 | +0.25 | 0.1713 | **未检出** |
| 专业背景 | **+0.85** | **0.0034** | −0.10 | 0.6493 | **方向相反 → 存疑** |
| 价值观 | **+0.70** | **0.0018** | +0.40 | 0.1189 | **两指标同向，一显著** |

**为什么必须并列两个指标**：「视角覆盖数」用学科词表，**天生偏袒「专业」维度**；
「决策要素完备度」**与专业无关**。两个指标方向相反，就是指标偏袒的证据。

## 怎么自己复算

**最直接的一条：验证「成员必须异构」**

```bash
cd experiments
python - <<'PY'
import json, os, statistics

R = "2026-09-16_人格消融_n20/runs"
LEX = {  # 简化词表；完整版见 analysis/
  "计算机": ["技术","架构","算法","系统","数据","实现"],
  "教育学": ["教学","学生","学习","课程","教师","课堂"],
  "心理学": ["动机","情绪","认知","心理","焦虑","意愿"],
  "管理学": ["流程","资源","组织","机制","执行","管理"],
  "社会学": ["群体","文化","规范","关系","公平","传播"],
  "经济学": ["成本","收益","激励","投入","效用","价格"],
}
def dims(t):
    return sum(1 for ws in LEX.values() if any(w in t for w in ws))

vals = {}
for fn in os.listdir(R):
    d = json.load(open(os.path.join(R, fn), encoding="utf-8"))
    if d.get("status") == "ok" and d.get("report"):
        vals.setdefault(d["arm"], []).append(dims(d["report"]))

for k in ("E0_零异构", "E1_产品默认"):
    print(k, "n=%d 均值 %.2f" % (len(vals[k]), statistics.mean(vals[k])))
PY
```

**预期输出：`E0 4.60` / `E1 5.65`**

> 用完整词表（`analysis/`）会让 SD 略有不同，但**均值完全一致**。
