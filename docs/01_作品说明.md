# 群智 V15 —— 科研决策预演智能体（参赛作品说明）

## 一、作品一句话

**不是人问AI答，而是AI团队替你预演决策。**

输入一个科研/教研问题，系统自动判断课题复杂度，组建 6 人多学科虚拟团队（三层人格系统 × 8 专业）深度研讨：讨论前每位成员先形成**认知锚点**，讨论中主教练全程**知识库检索（知网/arXiv）+ 联网搜索**、审计、干预，最终产出**决策预演报告**：**决策建议 + 认知盲区 + 涌现洞察 + 风险预警**（不是研究结论，而是供决策者在投入资源前自检的多视角材料）。

**边界先说清**：我们不宣称"用了群智决策就更准"（这件事我们没测出来）。可验证的价值是两句：**发现认知盲区 + 讨论过程可归档**。

## 二、核心架构

```
统一网关 FastAPI（:5020）· A2A 接口（:5080）· /api/{sandbox,coach,review,presets,feedback}
  ├─ 讨论引擎：三层人格 · 8 专业 × 6 人 · 信息不对称 · 认知锚点 · 记录可重放
  ├─ 主教练：多源学术检索（11 个检索源插件）· 联网搜索 · 安全净化 · 选择性注入 · 审计干预 · 复杂度分级
  └─ 评审委员会：v3 五维（快，约 40 秒）· v6 成对判定（准，约 160 秒，锚点自检 + 独立风险栏）
```

**技术栈**：Python FastAPI + requests 直连（硬超时），不使用 OpenAI SDK（多模型）+ 博查 Web Search API + 多源学术检索装置（11 源并发 + 五道质量闸门 + 期刊分级）+ 前端 HTML/JS。

**部署形态**：腾讯云 7×24 常驻（systemd）；**双环境隔离**（线上稳定版 + 体验版并行互不影响）；评审器与检索源均为可插拔插件。

### 3.3 自我证伪：我们把 v3 的评分尺子下线了

| 项 | 事实 |
|---|---|
| v3 的 1–10 分尺子 | 在同一批 **18 对**材料上**只挑对 8/18（44%）**，**低于瞎猜的 50%** |

## 四、实验支撑（按证据强度排序）

### 4.1 先立口径：两批工作，不可混用

| 批次 | 数量 | 性质 | 构成 |
|---|---|---|---|
| **评审记录** | **798 轮** | 过程记录 | 566 主 + 150 复现 + 82 补充 |
| **对照实验** | **172 次** | 对照实验 | 三臂对照 **32** + 人格消融 **140** |
| （另）盲区对照 | 128 份产出 | 对照产出 | 3 方 × 6 单元，单 AI 臂 **20 次采样** |

- 798 轮评审记录中 **563 份**已生成 v3 五角色双模型评审（566 轮里 3 轮调用失败）。
- **172 次对照实验与 798 轮评审记录是两批完全不同工作，不可混用、不可相加。**
- 凡"率值/分数"只出自评审记录；凡"p 值/效应量"只出自对照实验。

### 4.2 【最强】成员异构 > 完全同质

| 项 | 数值 | 来源 |
|---|---|---|
| 覆盖维度差 | **同质组低 1.05**（即 +1.05）| 人格消融 **140 次**（每组 n=20） |
| 显著性 | **p = 0.0012** | 同上 |
| 效应量 | **dz = −0.99（大效应）** | 同上 |
| 独立复现 | **p = 0.015，d = +1.38** | 三臂对照 **32 次** |

两个独立实验、方向一致、都显著——**这是目前覆盖度类结论里最清晰的一条**。
**但它的适用范围仅限「覆盖维度」这一个代理指标**，见下方⚠️。

> ⚠️ **但这条也只成立于「覆盖维度」这一个代理指标**：同一份人格消融实验显示
> **题目对覆盖数的影响（1.37 个维度）比配置（1.15 个维度）还大**；
> 而在与专业无关的「决策要素完备度」上，认知原型 / 专业 / 价值观三维 **都不显著**
> （p=0.17 / 0.65 / 0.12）。报告原文自陈：「**所有基于覆盖数的结论都要打折扣**」
> 「**要回答「决策质量好不好」，只能靠人类盲评 —— 这一步我们还没做**」。
> 所以准确说法是：**在覆盖维度上，成员异构优于完全同质**；
> **不能**写成「成员异构提升质量」，也**不宜**用「必须」这种规范性措辞。


### 4.3【限定结论】6 人团队 vs 单模型多视角：**只在「视角覆盖数」这个代理指标上**判定等价

| 项 | 数值 |
|---|---|
| 视角覆盖数 | 5.50 vs 5.88，p=0.026 → **TOST 判定等价** |
| token 比 | **18.5 倍**（45,074 / 2,437）—— ⚠ 两者工作量不同，不是等价产出的成本比较 |
| 结论 | **覆盖度上等价；token 比 18.5 倍（工作量不同，不是成本优势）** |

- 因此**不得表述为"团队显著强于单模型"**——该说法已被三臂对照推翻。
- 团队价值在**维度广度**（p=0.015，d=+1.38）与**过程可归档**；凡涉及单 AI 一律写"**在该题单 AI 20 次采样中未出现**"，不写"想不到"式断言。

### 4.4 【诚实负结果】条件对质量无可检出影响

| 检验 | 数值 |
|---|---|
| 条件解释综合分方差 | **2.7%** |
| 方差分析 | F(12,550) = 1.291，**p = 0.219** |
| 真涌现率齐性 | χ²(12) = 12.63，**p = 0.397** |
| 同条件内对半拆分率差 | 平均 **11.7 个百分点**（本实验噪声水平） |

> **"未检出显著" ≠ "确认无影响"**——既可能确实无效应，也可能被记录间波动掩盖，当前样本量下不可区分。

### 4.5 【过程指标】真涌现率：只描述过程，不作质量证据

| 指标 | 数值 |
|---|---|
| 真涌现率（权威口径） | **57.7%（325/563）** |
| 真涌现率（有判定样本内） | **73.9%（325/440）** |

- 它**与"涌现度"评分冗余**：阈值一致率 98.6%、Jaccard 0.979——同一把尺子的两种写法。
- 正确表述：**"57.7% 的产出被批评家判定为真涌现"**，仅作过程描述。

### 4.6 【仅组间比较】v3 评审分与系统质量

| 指标 | n | 数值 |
|---|---|---|
| 综合分 | 563 | 7.95 |
| 深度/广度/实用性 | 562/562/551 | 7.96/8.19/8.62 |
| 涌现度/分歧质量 | 440/440 | 6.73/7.85 |
| 审计综合（内容可靠性） | 557 | **8.11** |
| 评审依据覆盖率 | 2555 个维度实例 | **100%**（全部附原文依据） |
| 安全实测 | — | 注入攻击（指令覆盖 / 角色冒充 / 零宽字符）**在测试样例中**均被拦截 |

> 8.11 等分数**仅用于组间相对比较**（同一把尺子量不同配置），**不作绝对质量等级背书**。

### 4.7 【已推翻】旧的卖点，我们不再写

| 曾宣称 | 现状 |
|---|---|
| 最优人格显著优于默认（t=4.386, d=0.543, p<0.0001） | ❌ **已推翻**，重算 **d≈0.05**（⚠ 该重算基于 review_db_v3，属已作废的 798 批，且该批评分被匹配 Bug 污染 —— **此数不作结论**） |
| 团队显著优于单模型 | ❌ **已推翻**，三臂对照 **TOST 判定等价**（p=0.026） |
| 决策质量提升 | ❌ **我们没测出来**，不宣称 |

### 4.9 关于 336 的正确说法（保留并加强）

三层人格系统提供 **336 种理论组合空间**（7 认知原型 × 8 专业 × 6 价值观）。这是**设计事实**，不是实验结论，**更不是优势主张**——实测人格维度最优 vs 默认 **d≈0.05（可忽略；⚠ 该值来自已作废评审库，不作结论）**。有实证支撑的是**"成员之间应当有差异（覆盖维度上有数据支持）"**（p=0.0012，dz=−0.99；独立复现 p=0.015，d=+1.38），故卖点收敛为**「认知盲区挖掘 + 多视角 + 主教练干预」**。

### 4.10 已知局限（我们自己写出来）

| 局限 | 现状 |
|---|---|
| "主教练干预""信息不对称"两根支柱 | **尚无消融对照**，目前是设计选择，不是已验证结论 |
| 8 类干预指令 | 未逐条量化各自边际贡献 |
| 评审独立性 | AI 五角色独立评审，**无人类盲评**；生成与评审同源，无法排除自我偏好 |
| 可复算边界 | 全局指标与记录级统计可当场复算；组级统计因原始组标签不全**不能独立复算**，组表降级为附录 |
| 体验规模 | "7×24 常驻"指服务可用性，**尚无外部用户规模数据** |

## 五、答辩演示脚本（5 分钟）

```
0:00 理念开场："你的方案有盲区，你自己看不到"
0:30 现场输入课题（或选预设）："大学生使用AI写作业，学校该禁止还是引导？"
     + 你的想法："应该引导，但不知道怎么落地"
1:00 主教练知识库检索（11 个学术检索源）+ 联网检索，组建 8 专业 × 6 人 AI 团队
2:00 讨论快进（主教练干预、深批者追问登场；讨论记录可现场回放）
3:00 输出《教研决策建议书》+ 人话报告：
     · 一句话结论/三步行动/核心洞察/关键分歧/风险
     · 🎯 你的认知盲区（评委最震撼）
4:00 单智能体对比：该题单 AI 20 次采样中未出现的视角，团队给出了
4:30 证据背书：798 轮评审记录 + 172 次对照实验（成员异构 p=0.0012）
5:00 理念回收
```

> 加演：切到 **v6 成对判定评审**，演示"锚点自检未过则不出分"。
> 若评委追问「多智能体是不是更强」——**分三句答，不能一句「等价」打发**：
> ① 我们**唯一测过**的指标是「视角覆盖数」（覆盖了几个专业维度），在这项上 **TOST 判不出差别**（p=0.026），token 比 18.5 倍；
> ② 但这个指标是**关键词匹配的代理**，报告自己写明「一份广而浅的报告也能拿到高覆盖」，**测不出决策质量**；
> ③ 所以**我们不宣称更强，也不宣称等价**——有数据支撑的正向结论只有「成员之间应当有差异（覆盖维度上有数据支持）」（p=0.0012）。
