## 二、系统规模（全部来自代码实测）

| 项 | 权威值 | 依据 |

| **价值观** | **6 种** | `VALUE_ORIENTATIONS`：效率/公平/创新/人文/实用/长远 |

## 三、三条不能混的说法

| ❌ 错误说法 | ✅ 正确说法 |

## 四、成本与 token（只陈述事实，不做倍数比较）

| 项 | 权威值 | 依据 |
|---|---|---|
| 一次完整预演 | **37 次 API 调用 · 47,261 token** | `token_stats_3round.json` 实测账单 |
| 成本 | **¥0.16 / 次** | 同上账单 |
| 耗时 | **模型侧约 110 秒**（token 账单那一次运行）；端到端 **两批实测**：<br>· 2026-10-24 前 12 次：中位 **160 秒**，区间 142–196 秒<br>· 2026-10-26 复测 2 次：**187 / 263 秒**（报告变长后变慢）<br>**现行对外口径：约 3–4 分钟** | 两套口径，勿混。⚠ 2026-10-26 复测 n 仅 2，但方向明确（报告更长 → 更慢） |
| 快速预演 | 7 次调用 · 7,571 token · ¥0.03 · 约 27 秒 | 同上 |
| 单模型多视角（C 臂） | 1 次调用 · 2,437 token | 三臂对照 |
| 6 人团队（A 臂） | 37 次调用 · 45,074 token | 三臂对照（**另一批运行**，与上表 47,261 token 非同一批，勿相减）|
| 启动阶段耗时 | **约 13 秒**（占全流程约 8%，瓶颈在模型侧）| 12 次实测 |
| 每角色信息片段 | **6 段，长度不等（40–80 字）**，每段带明确的「缺什么」| 引擎 `_generate_dynamic_infos`。**说明**：6 段与「命中几个源」不成一对一 —— 段是按角色生成的，会把命中的文献**分配**到这 6 段里；命中 5 个源时某些段会共用同一来源，不会凭空多出一段 |
| 认知原型维度 | 覆盖 −0.10（**p=0.6493**）、要素 +0.25 → **未检出** | 140 次消融单维拆解 |
| 数字可复算项 | **167 项**（全包数字逐条可追溯）| 复算报告 |

> 且**内容质量从未被评估**。价值没测，任何倍数结论都无依据。
> 2026-10-24 已从全部材料中删除「**成本差** 18.5 倍」「**约 6 倍**」两种表述。（注：**token 比 18.5 倍**作为事实陈述保留，它指两臂 token 总量之比，不代表成本优势。）

## 五、效果类结论及其边界

| 结论 | 数据 | 能说到哪一步 |
|---|---|---|
| **成员必须异构** | 140 次消融：4.60 vs 5.65 维，＋1.05，p=0.0012，dz=−0.99 | ✅ 成立。鲁棒性：门槛收紧到「每学科≥3种词且≥20次」仍 +0.90 维 |
| **同质化的代价（三臂口径）** | 三臂对照：A 臂 5.50 vs B 臂 4.25，差 **1.25**（n=8/臂）| ✅ 成立，但与上面 140 次消融的 **1.05** 是**两个不同实验**，不可混用 |
| 单维拆解 | 价值观 ＋0.70（p=0.0018, dz=+0.81，显著）/ ＋0.40（p=0.1189，不显著）—— 两指标同向但**只有一半显著**；专业 ＋0.85/−0.10（一涨一跌）；认知原型 −0.10/＋0.25（未检出）| 只有**价值观**可作卖点 |
| **覆盖度对照** | A 5.50 vs C 5.88（**C 名义更高**），TOST p=0.026 在 ±1 维边界内判定等价 | ⚠ 仅「视角覆盖数」一个指标；**内容质量未评估**，既不能证明更好，也不能证明更差。**注意：C 臂名义值更高（5.88 > 5.50）**，我们**不把「等价」读作「我们更优」**；差异可在 ±1 维边界内视为等价，且 C 臂只做 1 次调用、无讨论过程与审计产物 |
| 主教练干预 | 68 条真实记录 | ⚠ **效果无法归因**（无对照实验设计），只陈述机制，不宣称效果 |
| 真涌现率 | 三个口径并存，**分母不同不可混**：325/563 = **57.7%**（分母是 **566 条主实验记录中的 563 条**已生成 v3 评审者，**不含** 150 复现 + 82 补充）；325/440 = **73.9%**（仅统计有涌现判定的）；196/280 = **70.0%**（计算机类 6 个主条件）| ✅ 三个数均经 review_db_v3 复算可还原 |
| 视角覆盖数这个指标 | 6 张学科关键词表命中张数 | ⚠ **关键词计数的代理指标**，不是质量指标；某学科出现 1 个词即得 1 分 |
