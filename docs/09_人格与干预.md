## 一、人格不是"人设描述"，是结构化参数注入

### 1.1 每个成员由三元组定义

```python
SandboxPlayer(name, prototype_key, profession_idx, value_idx, value_weights)
#  ├─ 认知原型 prototype_key   7 类：hunter/trader/ghost/gambler/diplomat/skeptic/critic
#  ├─ 专业背景 profession_idx  8 类：计算机/教育/心理/管理/社会/经济/法学/医学
#  └─ 价值观体系 value_idx     6 类：效率/公平/创新/人文/实用/长远
```

三者独立组合：**7 × 8 × 6 = 336 种配置空间**（这是理论空间，不是效果声明——
实测人格维度效应量较小 d≈0.05（⚠ 来自已作废评审库，不作结论），已在作品文档 7.x 如实披露）。

### 1.2 人格如何进入每次发言（真实模板）

以下是引擎**实际发送**给模型的发言提示词（`prompts.py` 中 `SPEAK_PROMPT`，变量已填入）：

```
你正在参与一场建设性的学术讨论。

【你的身份】
姓名：乙
性格倾向：检验者——从反面推演方案的可行性，追问边界条件和潜在风险。
专业背景：心理学——从动机、认知偏差和行为模式的角度分析问题。
价值取向（多价值观权重分布，权重越高越主导你的判断）：
  人文关怀🤲（权重50%）：关注人的感受与尊严，反对把人当作指标
  效率优先⚡（权重18%）：……
  公平优先⚖️（权重13%）：……
（你的核心价值取向：人文关怀——关注人的感受与尊严）
当前讨论温度：0.79

【讨论课题】如何提升师范生课堂参与度？
【你已知的信息】你掌握某高校师范生课堂参与度的问卷数据（来源：……），
              但不知道教师端的实际执行阻力……
【当前轮次】第2轮
【其他参与者】甲, 丙, 丁, 戊, 己
【近期讨论记录】
 甲说：……
 丙说：……

【发言要求】
1. 从你的专业背景和价值取向出发，贡献一个具体的观点或补充一个被忽略的视角。
2. 如果你有不同看法，请从自己的信息背景出发提供补充视角，而非直接否定他人。
3. 避免空泛的赞同或反对，每次发言都应该推进讨论的深度。
4. 语言自然、沉稳、有思考感，长度60-150字。
5. 当讨论进入方案收敛阶段时，请为你的方案提供可验证性说明：如观测指标、
   最小实验验证方法、或可能的失效条件。若无法提供，请标注"待验证"。
6. 如果主教练要求进行"反事实推演"，请回答："如果完全不采用当前方案，
   可能出现的最坏情况是什么？有什么替代路径？"
```

**关键点（为什么这不是"风格伪装"）**：

| 机制 | 说明 |
|---|---|
| **价值观是权重分布，不是形容词** | 不是"你重视人文关怀"，而是"人文关怀 50%、效率 18%、公平 13%…（权重越高越主导判断）"——**每个成员的具体数字不同**，直接影响其取舍 |
| **信息不对称由 `known_info` 承载** | 每个成员拿到的信息切片不同（如"你掌握问卷数据，但不知道教师端阻力"），且明说"不知道什么"——这是盲区的来源 |
| **输出格式被约束到可检验** | 第 5 条强制要求"观测指标/最小实验/失效条件"，无法提供则标注"待验证"——**人格差异最终落成可核查的输出差异** |
| **个体温度不同** | `temperature=0.5~0.95`，随成员与轮次波动（见 1.3）|

### 1.3 人格在讨论中会演化（不是静态人设）

```python
def fluctuate(self, round_num, max_rounds):
    # 温度：±0.08 随机漂移 + 每轮 +0.02（讨论深入更放开）
    drift = round(random.uniform(-0.08, 0.08), 3)
    self.temperature = max(0.5, min(0.95, 0.75 + drift + round_num * 0.02))
    # 价值观：主价值观锚定 50%，其余权重每轮 ±0.04 漂移后归一化
    for k in weights:
        if k != self.value_idx:
            weights[k] = max(0.02, weights[k] + random.uniform(-0.04, 0.04))
    ...归一化后：weights[self.value_idx] = 0.5
```

即：**主价值观恒定锚定 50%**（保证角色一致性），**其余 50% 每轮小幅漂移**（模拟人在讨论中被说服/被刺激而调整权重）。

## 二、教练干预：时机、触发条件与指令集（回应"干预是否随机"）

### 2.1 干预何时发生

```python
intervention_queue = list(self.coach_interventions)
for rnd in range(1, self.max_rounds + 1):
    ...
    if rnd == 2 and intervention_queue:      # ← 固定在第 2 轮注入
        for intervention in intervention_queue:
            ...注入讨论上下文
    ...
    if rnd % 2 == 0 and rnd < self.max_rounds:   # ← 偶数轮触发快速投票
        vote_thread = ...
```

| 机制 | 规则 |
|---|---|
| **干预注入时机** | 第 2 轮开始时（此时成员已亮明立场、分歧显现）|
| **干预内容来源** | 预生成的干预队列（`coach_interventions`），由组队阶段按课题生成 |
| **投票环节** | 偶数轮（2、4…）触发 `_quick_vote`，检验共识是否真实 |
| **何谓"第 2 轮"依据** | 收敛性实验：讨论第 2 轮后进入收敛区（首轮新颖度 1.00 → 第 2 轮骤降至 ~0.23）——**在第 2 轮介入，正好卡在"分歧已现、尚未收敛"的窗口** |

### 2.2 干预不是随机句子，是"审计发现 → 指令映射"

引擎内置 8 类审计关注点，每类**对应一条具体干预指令**（`AUDIT_CONCERN_MAP`）：

| 审计发现的症状 | 触发的干预指令 |
|---|---|
| 可验证性缺失 | 【可验证性声明】请为当前方案明确观测指标、基线数据和预期变化方向 |
| 共识幻觉 | 【概念冻结】请对当前使用的核心术语给出操作化定义，并区分理解是否一致 |
| 机制过载 | 【机制预算】请评估每增加一个机制所付出的互斥成本，并考虑删除一个旧机制 |
| 技术乐观主义 | 【红队测试】请预设一个最危险的失败场景：该方案被滥用时会发生什么？如何反制？ |
| 伦理缺位 | 【伦理审查】该方案是否尊重所有相关方的数据自主权、公平性和尊严？ |
| 人格同质化 | 【视角切换】请暂时以批判者或对立价值取向审视当前方案，找出至少一个被集体忽略的盲区 |
| 理想执行者假设 | 【降级运行】请假设执行者处于疲惫、抗拒或资源匮乏状态，该方案如何自动降级运行？ |
| （主动干预）| 【反事实推演】如果完全不采用当前方案，可能出现的最坏情况是什么？有什么替代路径？ |

**证据**：在真实运行的讨论日志中可观察到干预落地的痕迹，例如课堂参与度案例：
```
[主教练干预] 请暂停讨论，对所有核心术语给出操作化定义。      ← 概念冻结
[主教练干预] 请评估每增加一个机制所付出的互斥成本，并考虑删除一个旧机制。 ← 机制预算
```

### 2.3 仍然存在的局限（如实说明）

- **干预强度未做分级**：当前 8 类指令是"点到点"的文本注入，**没有强度参数**（如"轻度提醒 vs 强制改论点"）；
- **触发依赖预生成队列**：干预在组队阶段按课题预生成，**不是讨论中实时审计动态生成**（实时审计是下一步）；
- **干预效果的边际贡献未量化**：8 类指令没有逐条消融实验，所以"哪条最有用"目前无法回答
  （已在作品文档 7.3 列为已知局限）。

## 三、小结

| 质疑 | 本说明的回答 |
|---|---|
| 人格是否只是"风格伪装"？ | 不是——人格是**结构化三元组 + 价值观权重分布**，直接进入每次发言 prompt，并通过"必须给观测指标/最小验证/失效条件"约束到可检验的输出形态 |
| 人格是否静态？ | 会演化——主价值观锚定 50%，其余每轮 ±0.04 漂移，温度随轮次升温 |
