# 群智 · 检索来源说明（V15.5）

> 本文件回答评委的两个问题：**你们的信息从哪来？质量怎么保证？**
> 所有"可用/不可用"结论均为**实测结果**（2026-09-12，含 HTTP 状态码），不是文档推测。

## 三、五道质量闸门

每一条要注入给 AI 玩家讨论的信息，都必须依次通过：

### 闸门 1 · 低质源过滤
- **文库/资料站黑名单**（30+ 域名）：百度文库、豆丁、道客巴巴、原创力、人人文库、金锄头文库、
  淘豆网、咨信网、爱问共享资料、360doc 等；
- **作业题/试卷/答案页特征**：`请结合…谈谈`、`参考答案`、`字数不超过N字`、考试资料网、电大之家等；
- **文件名特征**：标题含 `.doc` / `.docx` / `.ppt`（文库页的典型形态）；
- **论坛灌水/广告特征**：积分、下载次数、VIP 专享、扫码关注等。

> 实测效果：单次检索剔除 **9–13 条**低质结果。

### 闸门 2 · 学术时效过滤（默认近 3 年）
- 学术类文献只收最近 **3 年**；不足 3 条时放宽至 5 年（并在日志中说明）；
- 仍不足时，用最新的较早文献补位，且**在注入文本中显式标注"（较早文献，仅作背景参考）"**；
- 年份识别优先采用权威信号（`发表时间：` / `XXXX年第N期`），而非正文中出现的任意年份
  —— 此前曾出现《学周刊》2014 年论文因正文含 2023 而被误判为"3 年内"的问题，已修复并回归验证。

> 为什么要"补位"：如果严格剔除后信息池只剩 1–2 条，6 个玩家会拿到同一份信息，
> 直接削弱本系统的核心机制（不对称信息注入）。因此宁可**标注后保留**，也不让池子塌缩。

### 闸门 3 · 国际源相关性裁判
国际数据库对中文课题的模糊匹配噪声很大。实测案例：课题"低温环境下锂电池 SOC 估算误差超 8%"，
Crossref 返回过"液压电梯在特殊环境下的适应性研究""5G 网络环境下的通信协议安全性分析与改进"
——它们只在"低温/环境/改进"这些**通用修饰词**上撞词，研究对象完全不同。
由于纯词面重合度无法区分（该液压电梯论文与课题的重合度高达 8），系统对国际源候选再做一次
**LLM 相关性裁判**，剔除"只共享修饰词、研究对象不同"的文献。

> 实测效果：5 条噪声候选剔除 4 条，只保留真正相关的文献。

### 闸门 4 · 排序与注入上限
- 学术来源（知网 / Crossref / DOAJ / PubMed / OpenAlex / arXiv）**优先排序**，
  避免博查返回的文库/作业页挤掉真正有价值的文献；
- 最终注入 **≤8 条**，避免提示词过长、单条信息被稀释；
- 统计口径：`results_count` = 最终注入条数，`raw_count` = 过滤前原始条数（可在日志核对过滤强度）。

## 四、中文平台接入调研（逐平台实测结论）

> 说明：多数中文平台面向"人工检索 + 登录下载"，没有面向程序的公开接口。
> 我们只接入**有公开 JSON 接口**的来源；对需要登录态或明文禁止抓取的站点**不做爬取**，以规避合规风险。
> 知网是唯一例外——通过使用者自己的登录凭据（`cookies/cnki.json`）在**使用者本地**发起检索，
> 凭据不随代码分发、不上传服务器。

### 4.1 已接入（三个，实测 HTTP 200，零鉴权）

| 平台 | 接口 | 实测证据 |
|---|---|---|
| **国家哲学社会科学文献中心** | `POST https://www.ncpssd.org/searchHandler/search`（form-urlencoded） | 新建会话 cookie 为空 `{}`（零鉴权）；`师范生` → total=10047，`课堂参与度` → total=194；返回字段含 title/creator/remark（摘要）/years/doi |
| **ChinaXiv**（中科院预印本） | `POST https://chinaxiv.org/api/search`（JSON） | `{"searchText":""}` → total=**47465**（全库）；`{"searchText":"深度学习"}` → total=358，返回 90 字段（含 DOI、摘要、期刊、关键词） |
| **NSTL 国家科技图书文献中心** | `POST https://www.nstl.gov.cn/api/service/nstl/web/execute?target=nstl4.search4&function=paper/pc/list/pl` | `education` → total=2474105；`师范生 课堂参与度` → 命中 5 条（含 DOI） |

**两个实测踩到的坑**（已写进代码注释，避免后人重复踩）：

1. **NCPSSD 裸词一律返回 0 条**——`search=教育` 与 `search=education` 都是 `total=0`。
   必须带字段前缀：`(IKTE="关键词" OR IKST="关键词")`（IKTE=题名、IKST=主题词）；
   且多词短语在同一字段内做精确匹配也会 0 条，必须**拆词后用 OR 连接**。系统因此增加了
   "用 LLM 把课题拆成 3-5 个中文关键词"的步骤。
2. **ChinaXiv 的分页参数名是 `pageSize` 不是 `size`**——传 `size` 会被静默忽略并固定返回 10 条；
   `q` 参数名同样被静默忽略（传 `{"q":"education"}` 会返回全库 47465 条而不报错）。

### 4.2 未接入（实测失败或不合规）

| 平台 | 结论 | 实测依据 |
|---|---|---|
| PubScholar 公益学术平台 | ❌ 不可用 | `GET /api/search?searchWord=education` → **403**（网关级拦截，整树 `/hky` 亦 403） |
| 国家预印本平台（中信所） | ❌ 不可用 | 只有 sitemap 全量通道（含 20000 篇），**参数被忽略、无法按关键词检索**，不满足检索需求 |
| 国家科技报告服务系统（NSTRS） | ❌ 不可用 | 检索强制登录 |
| 国家知识产权局专利检索 / 专利之星 | ❌ 不可用 | 瑞数动态防护 + 域名失效 |
| 欧洲专利局 Espacenet / EPO OPS | ❌ 未接入 | 站点 Cloudflare 拦截；OPS 需申请 Key 且配额极低 |
| 中科院机构知识库服务网格 | ❌ 已停服 | 实测无法访问 |
| 百度学术 / 万方 / 维普 | ❌ 不可用 | 无公开接口，站点有反爬（维普为瑞数动态防护） |

> 结论：与其接入一堆需要账号、随时可能封禁的抓取通道，不如把**免 Key 且稳定**的
> NCPSSD / ChinaXiv / NSTL / Crossref / DOAJ / PubMed / OpenAlex / arXiv 做深做透
> ——它们已覆盖中文社科、中文科技、中英文预印本、国际期刊、开放获取与医学健康，
> 且在评委机器上**开箱即用、无需申请任何账号**。

## 五、如何扩展来源（开发者）

新增一个来源只需三步（参考 `app/rag/scholarly_sources.py`）：

```python
def search_yoursource(query: str, rows: int = 6, max_age: int = 3) -> list:
    """返回统一结构：[{title, url, summary, source, year, doi}]"""
    # 1) requests 直连 + 硬超时（timeout=20），失败返回 [] 并打印一行日志
    # 2) summary 里带上"作者/期刊/发表时间/被引/摘要"，供后续时效与相关性判定使用
    # 3) 不要抛异常——任何失败都不能影响主流程
```

然后在 `route_sources()` 中按课题类型登记该来源即可，它会自动经过上述五道闸门。

## 六、这套检索设计解决了什么真实问题

| 问题（实测发现） | 处理 |
|---|---|
| 教育类课题的网页结果大量是文库/作业页，剔除后信息池只剩 1 条 | 新增 Crossref/DOAJ/PubMed 学术源 + 高检索量（3 查询 × 8 条）+ 池子下限补位 |
| 2014/2018 年的老论文混进"近 3 年"结果 | 修正年份识别逻辑（优先"发表时间/年+期"），回归测试 6/6 通过 |
| 国际源对中文课题返回大量不相关文献 | 增加 LLM 相关性裁判 + 英文检索式（中文课题先转英文再喂 PubMed/DOAJ） |
| 中文课题喂 PubMed 命中化学晶体学论文 | 加语言门控：纯中文课题必须先用 LLM 生成英文检索式 |
| 学术文献被文库结果挤出注入列表 | 候选排序时学术来源优先，再进入过滤与注入 |
