# 群智 QunZhi · 多智能体决策预演系统

> **不是人问 AI 答，而是 AI 团队替你预演一遍决策。**
>
> 输入一个课题（一句话即可），6 个异构 AI 角色各持不同的信息片段展开讨论，
> 主教练按本地信号逐轮判断是否干预，最终产出一份约 300 字的预演报告 ——
> 包含**一句话结论 + 行动建议 + 你的认知盲区 + 可核对的参考文献**。

## 这个项目为什么存在

我们让 DeepSeek、GLM、Qwen 三家模型回答同一个问题：「如何提升师范生课堂参与度」。

结果是 **5,210 字、71 条建议，没有一条说「这么做会崩」**。

> 来源：项目初期的一次同提示词对比测试（temperature=0.7，DeepSeek 1,783 字 / GLM 1,500 字 / Qwen 1,927 字，合计 5,210 字、71 条）。这是**观察性测试**，不是消融实验，不作为统计证据。

71 条都在回答「可以做什么」，没有一条在回答「会死在哪儿」。

**决策的难，从来不是不知道做什么，是不知道哪一条会崩。**

所以我们做的不是「更聪明的问答」，而是**预演** —— 让一个团队先替你走一遍，把会崩的地方摆出来。

## 它跑起来是什么样

```
一句话进去 → 五个自动步骤 → 一份预演报告出来
```

| 步骤 | 做什么 |
|---|---|
| **① 意图判定** | 判断课题类型；若过于模糊（如「做一下课堂改革」）会追问「成功判据是什么」 |
| **② 复杂度分级** | 3 档，决定讨论轮数与检索量 |
| **③ 检索注入** | 11 个检索源插件（10 学术库 + 1 联网搜索，非「11 个学术源」）→ 前置 4 道过滤 → 5 道质量闸门 → 6 段不等的信息片段 |
| **④ 组队讨论** | 6 个角色（认知原型×7 / 专业×8 / 价值观×6，336 条设计路径），主教练逐轮判断是否干预 |
| **⑤ 生成报告** | 一句话结论 + 行动建议×3 + 认知盲区×4 + 参考文献 |

**实测**：12 次运行，耗时中位数 **160 秒**，区间 142–196 秒；启动仅占 13 秒，瓶颈在模型侧。
**成本**：一次完整预演 **37 次 API 调用 / 47,261 token / ¥0.16**；另有一个轻量的「快速预演」模式：**7 次调用 / 7,571 token / ¥0.03 / 约 27 秒**。

> 注：报告中的「认知盲区」等**定性结论来自模型的判断，未经人类验证**；本项目的量化证据只覆盖「视角覆盖数」这一代理指标。

## 三个机制

```
团队异构 × 信息不对称 × 主教练干预 = 真正的分歧
```

> ⚠️ **三者的证据强度完全不同，不能并列声称「缺一不可」：**
> - **团队异构** —— 有对照证据（140 次消融，覆盖维度 +1.05，p=0.0012）
> - **信息不对称** —— 有**设计事实**（每位角色拿到不同片段），但**无对照实验**
> - **主教练干预** —— 有**机制记录**（99 场中 68 场触发干预（69%）），但**效果无法归因**
>
> 「乘起来等于真正的分歧」是我们对机制的**假设**，不是被验证的结论。

| 机制 | 缺了会怎样 | 依据 |
|---|---|---|
| **团队异构** | 6 个 AI 说一样的话 —— 等于同一个人自问自答 | 140 次消融：异构 5.65 vs 同质 4.60，**差 +1.05**（异构更高）；p=0.0012，**dz=−0.99**。⚠ **dz 为负是方向编码**（E0 零异构 − E1 异构 的标准化差值），绝对值 0.99 表示**大效应**，与「差 +1.05」方向一致 |
| **信息不对称** | 所有人读同一份材料 —— 讨论退化成复述 | 每位角色拿到不同的 40–80 字片段，且刻意要求「互补与矛盾」|
| **主教练干预** | 几轮之后自然趋同 —— 没有人拉回来 | 68 场干预记录（共 99 场，触发率 69%）（**仅证明机制在跑，不证明效果**）；信号全部本地可算 |

## 我们不宣称什么

这个项目最有价值的部分，可能是**这些边界**：

| 不宣称 | 原因 |
|---|---|
| ❌ 「多智能体比单模型更聪明」 | 我们唯一测过的指标是「视角覆盖数」（关键词计数），**内容质量从未被人类评估** |
| ❌ 「主教练干预提升了效果」 | 无对照实验设计，无法归因 |
| ❌ 「336 条路径是优势」 | 336 是**设计基数**，不是效果优势 |
| ❌ 「多智能体更便宜/更贵 X 倍」 | 两臂产出不对等，且价值未测，任何倍数比较都无依据 |
| ❌ 「认知原型维度有贡献」 | 该维度未检出（覆盖 −0.10，p=0.6493）|

**MECE 地说：我们只有一条强证据 —— 「成员必须异构」（覆盖维度 5.65 vs 4.60，p=0.0012，dz=−0.99）。**
**注意：这条证据建立在「视角覆盖数」这一关键词计数的代理指标上 —— 它证明的是「想法覆盖得更广」，不是「决策质量更高」。**
另有一条较弱证据：「价值观」维度在两指标上同向 —— **覆盖 +0.70（p=0.0018, dz=+0.81，显著）**、**要素 +0.40（p=0.1189，不显著）**。即：**两指标同向，但只有一半显著**，且同样基于覆盖类指标。
**其余两维（专业背景、认知原型）我们不宣称。**

## 快速开始

```bash
cd src
pip install -r requirements.txt
cp .env.example .env      # 填入你自己的 API Key
python -m uvicorn app.main_gateway:app --port 5020
```

需要三个环境变量：`DEEPSEEK_API_KEY`（必需）、`BOCHA_API_KEY`（联网检索）、`GLM_API_KEY`（评审）。

**没有任何 Key 是本项目自带的** —— 你必须自己申请。

## 技术栈

- **后端**：Python 3.12 + FastAPI + `requests` 直连（硬超时，不用 OpenAI SDK）
- **前端**：主控制台为原生 HTML + JS（无框架）；`templates/classroom_sm.html`（学校平台轻量版）使用 **Vue 3（CDN 引入）**
- **检索**：11 个检索源插件 = **10 个学术库**（知网 / NCPSSD / ChinaXiv / NSTL / Crossref / DOAJ / PubMed / arXiv / OpenAlex / Semantic Scholar）+ **1 个联网搜索**（博查 Web，插件声明 `web=True`、明写「非学术库」）
- **编排**：自研，不用 LangChain

## 关于数据

实验数据全部随仓库提供。**《数字口径统一表》内的 167 项数字均可从原始记录复算**（不是「所有数字」—— 本包历史上刚被外部审核抓出 8 处硬伤，所以这句只能限定在口径表范围内）。

但也必须如实说：

- **决策质量至今没有人类盲评** —— 这是我们最大的缺口，写在 [`journey/01_一点反思_度量与数据问题.md`](journey/01_一点反思_度量与数据问题.md) 里
- **798 轮评审记录的评分被匹配 Bug 污染了 383/563 条**，整批作废，我们没有藏起来
- **主教练干预的效果无法归因** —— 只陈述机制，不宣称效果

**我们宁愿交出一份自己拆自己的材料，也不愿意让外面的读者替我们发现这些问题。**
