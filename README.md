## 这是什么

输入一个课题（一句话即可），6 个异构 AI 角色各持不同的信息片段展开多轮讨论，
一个「主教练」角色按本地信号逐轮判断是否介入，最终产出一份预演报告 ——
包含**一句话结论 + 行动建议 + 你的认知盲区 + 带编号的参考文献**。

```
课题：如何提升师范生课堂参与度？
你的想法：让学生多发言就行
        ↓ 3–4 分钟
报告：一句话结论 / 三步行动 / 认知盲区 ×4 / 文献 P1–P8（含期刊分级）
```

**它解决的不是「AI 不够聪明」，是「AI 不会告诉你哪条会崩」。**

## 核心结论（含失败的）

**只有一条强证据：成员必须异构。**

| 结论 | 数据 | 状态 |
|---|---|---|
| **成员必须异构** | 140 次消融：异构 5.65 vs 全同质 4.60，**+1.05**，raw p=0.0003，**Holm p=0.0012（family=4）/ 0.0015（family=5）**，dz=**+0.99** | ✅ **成立** |
| 「价值观」一维**只有覆盖度显著** | 覆盖 +0.70（p=0.0018）**显著**；决策要素 +0.40（p=0.1189）**不显著** | ⚠️ **两指标同向但只有一半显著 —— 只能算「无反向证据」，不能说「被验证」** |
| 「专业背景」一维有效 | +0.85（p=0.0034），但另一口径 −0.10（p=0.65）**方向相反** | ❌ **存疑，不宣称** |
| 「认知原型」一维有效 | −0.10（p=0.6493） | ❌ **未检出** |
| 多智能体**并不**优于单模型 | **单模型 5.88 > 团队 5.50**（差 −0.38）| ❌ **不成立** |

> **赤裸地说**：在这个指标上，**单模型比我们高**（5.88 vs 5.50）。
> 我们做过 TOST 等价检验，在**预设的 ±1 维边界内**判「等价」（p=0.026）——
> 但这只是说「差距在我们划定的边界内可忽略」，**不改变一个事实：单模型名义分数更高**。
> 谁要拿这一点说「多智能体没用」，我们没法反驳。
| 798 轮评审记录的**得分结论** | 匹配 Bug 污染 383/563 条 | ⛔ **整批作废，不可引用** |

完整口径见 [`docs/06_数字口径统一表.md`](docs/06_数字口径统一表.md) —— **那是本仓库唯一的数字权威**，任何文档与它冲突以它为准。

**指标说明**：以上「覆盖度」指**视角覆盖数**（6 个学科词表命中几个，满分 6）。它衡量「说得全不全」，**不是质量结论**。

## 我们没做到的

这一节比上一节更重要。

| 缺口 | 现状 |
|---|---|
| **决策质量从未被人类盲评** | 唯一测过的指标是关键词覆盖度。「盲区准不准」没人验证过 |
| **主教练干预效果无法归因** | 99 场中 68 场触发（69%），但**无对照设计**，只能证明机制在跑 |
| **样本量下限** | n=20 只能检出 ≥1 维的差异；「未检出」≠「无效」 |
| **只做了 4 个课题 × 5 个种子** | 换课题可能结论不同 |
| **没有任何真实用户** | 没有付费用户，没有机构采用 |
| **336 是设计基数** | 7×8×6 的组合空间，**不是实验结论，不是优势** |

```bash

pip install -r requirements.txt
cp .env.example .env          # 填入你自己的 Key
```

## 技术栈

- **后端**：Python 3.12 + FastAPI + `requests` 直连（硬超时，**不用 OpenAI SDK**）
- **前端**：主控制台原生 HTML + JS（无框架）；`classroom_sm.html` 用 Vue 3（CDN）
- **编排**：自研，**不用 LangChain**
- **检索**：11 个源 = 10 个学术库（知网 / NCPSSD / ChinaXiv / NSTL / Crossref / DOAJ / PubMed / arXiv / OpenAlex / Semantic Scholar）+ 1 个联网搜索（博查，**非学术库**）

**为什么不用现成框架**：早期试过，编排逻辑被框架的抽象吃掉，干预时机控制不了。这件事写在 [journey/](journey/) 里。

## 关于「798 轮作废」

这是本仓库最值得看的一段。

我们用 AI 做了 798 轮评审，看起来严谨。但后来发现：

```python
# sync_reviews_v3_to_coach.py 第 41-42 行
if r.get("topic") == topic and r.get("experiment_group") == exp.get("experiment_group"):
```

**用 `topic + group` 匹配，没用 `file_path`。** 同一组同一课题的多条实验，全部匹配到了第一条评审记录 —— **563 条里有 383 条张冠李戴**。

整批作废，只留档。**所有现行结论改为只来自可复算的客观指标。**

完整复盘：[`journey/01_一点反思_度量与数据问题.md`](journey/01_一点反思_度量与数据问题.md)

## 这个项目怎么来的

**它的前身是一个 AI 互相欺骗的博弈游戏。**

在游戏里，每个 AI 有隐藏目标、拿到的信息不全、必须判断谁在说谎。
后来我们发现：**真实决策里正在发生同样的事** —— 只是没人告诉你谁在骗你。

区别只有一个：游戏里你知道是假的，决策里你不知道。
